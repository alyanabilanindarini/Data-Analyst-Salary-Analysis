# Data Analyst Salary Analysis Using SQL

## Overview

This project was completed as part of a SQL learning program using MySQL. The analysis explores salary data related to Data Analyst roles to identify salary trends, job variations, and compensation factors.

## Case Study

This project aims to analyze Data Analyst salary data through several key aspects:

1. Identifying missing values in the dataset.
2. Exploring job title variations.
3. Identifying job titles related to Data Analyst roles.
4. Analyzing average salaries based on experience level and employment type.
5. Identifying countries that offer attractive salaries for entry-level and mid-level Data Analysts.
6. Determining the year with the highest salary increase from Mid-level to Senior-level Data Analyst positions.

## Data Overview

| Column | Description |
|----------|------------|
| work_year | Salary payment year |
| experience_level | Experience level (EN, MI, SE, EX) |
| employment_type | Employment type (FT, PT, CT, FL) |
| job_title | Job position |
| salary | Gross salary |
| salary_currency | Salary currency |
| salary_in_usd | Salary in USD |
| employee_residence | Employee residence |
| remote_ratio | Remote working ratio |
| company_location | Company location |
| company_size | Company size (S, M, L) |

## Key Findings

- The dataset contains no missing values.
- There are 9 job titles related to Data Analyst.
- Average salary increases as experience level grows.
- Full-time employees generally earn higher salaries.
- The United States and Canada offer the most attractive salaries for entry-level and mid-level Data Analysts.
- The highest salary increase from Mid-level to Senior-level Data Analyst occurred in 2022.
